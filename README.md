# JavaScript Mini Projects

This folder contains small JavaScript game projects used for learning and practice.

## Projects

- **guessTheNumberGame**: A higher-or-lower number guessing game. See higherOrLowerGame.js.
- **headsOrTails**: A simple coin flip simulator. See app.js in headsOrTails.
- **rockPaperScissor**: Rock-Paper-Scissors game. See app.js in rockPaperScissor.

## How to run

Open each project folder and run the corresponding JavaScript file with Node.js:

```
node <filename>.js
```

## Notes

These are simple console-based programs intended for practice and learning core JavaScript concepts.
